# 🔧 FixSnap AI

FixSnap AI is a simple AI assistant that helps users
understand everyday technical problems using photos.

## Features

- 📸 Upload a problem photo
- 🤖 AI image analysis
- 💬 Simple conversational troubleshooting
- 🛠️ Easy troubleshooting steps
- 📱 Send the latest answer to WhatsApp
- 🔍 Ask normal technical questions

## Technology

- Python
- Streamlit
- Google Gemini
- Twilio WhatsApp
